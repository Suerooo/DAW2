Enlaces y listas

Conectan documentos y organizan elementos.

Etiqueta <a>

Crea enlaces a páginas, archivos o partes de un documento.

Código

<a href="https://es.wikipedia.org/wiki/HTML">Visitar Wiki HTML</a>

Resultado

Visitar Wiki HTML

Atributos específicos

  • href: Indica la dirección a la que lleva el enlace.
  • target: Define dónde se abre el destino; por ejemplo, _blank abre otra pestaña.
  • rel: Describe la relación con el destino, como nofollow o noreferrer.
  • download: Solicita descargar el recurso en lugar de abrirlo, cuando el navegador lo permite.
  • hreflang: Indica el idioma del documento enlazado.

Multimedia

Insertan imágenes y controles de audio y vídeo.

Etiqueta <img>

Inserta una imagen en el documento.

Código

<img src="assets/images/example-landscape.svg" alt="Paisaje con montañas">

Resultado

Atributos específicos

  • src : Indica la ruta de la imagen.
  • alt : Proporciona un texto alternativo; se deja vacío si la imagen es decorativa.
  • width : Indica el ancho de la imagen en píxeles.
  • height : Indica el alto de la imagen en píxeles.
  • loading : Con lazy permite aplazar la carga hasta que la imagen se acerque a la zona visible.
  • srcset : Ofrece varias imágenes para distintas resoluciones o tamaños.
  • sizes : Indica el espacio previsto para la imagen cuando srcset utiliza descriptores de ancho.
  • decoding : Da una indicación al navegador sobre cómo decodificar la imagen.

Etiqueta <audio>

Incluye audio reproducible desde el navegador.

Código

<audio controls src="assets/audio/ding-sound-effect.mp3"></audio>

Resultado

Atributos específicos

  • src : Indica la ruta del archivo de audio.
  • controls : Muestra los controles de reproducción.
  • autoplay : Solicita reproducir el audio automáticamente; el navegador puede bloquearlo.
  • muted : Hace que el audio comience silenciado.
  • loop : Repite el audio al terminar.
  • preload : Sugiere cuánto cargar por adelantado: none, metadata o auto.

Etiqueta <video>

Permite insertar un vídeo con reproductor propio.

Código

<video controls width="320" poster="assets/images/video-cover.svg"><source src="assets/video/html-tutorial.mp4" type="video/mp4"></video>

Resultado

Atributos específicos

  • src : Indica la ruta del archivo de vídeo.
  • controls : Muestra los controles de reproducción.
  • poster : Indica la imagen que se muestra antes de reproducir el vídeo.
  • width : Define el ancho del reproductor en píxeles.
  • height : Define el alto del reproductor en píxeles.
  • autoplay : Solicita reproducción automática; el navegador puede bloquearla, especialmente con sonido.
  • muted : Hace que el vídeo comience sin sonido.
  • loop : Repite el vídeo al terminar.
  • preload : Sugiere cuánto cargar por adelantado: none, metadata o auto.
  • playsinline : Solicita reproducir el vídeo dentro de la página, sin pasar automáticamente a pantalla completa.

Formularios

Recogen información introducida por el usuario.

Etiqueta <form>

Agrupa campos y controles para introducir datos.

Código

<form action="/enviar" method="post"><input name="nombre"><button>Enviar</button></form>

Resultado

Atributos específicos

  • action : Indica la URL que recibe los datos al enviar el formulario.
  • method : Elige el método de envío, normalmente get o post.
  • enctype : Define el formato de envío; multipart/form-data permite enviar archivos con post.
  • target : Indica dónde se muestra la respuesta al envío.
  • autocomplete : Permite o desactiva el autocompletado del formulario.
  • novalidate : Desactiva la validación automática del navegador al enviar.

Etiqueta <label>

Asocia un texto descriptivo con un control de formulario.

Código

<label for="nombre">Nombre</label><input id="nombre">

Resultado

Atributos específicos

  • for : Asocia el texto de la etiqueta con un control concreto del formulario.

Etiqueta <input>

Crea campos de entrada de distintos tipos.

Código

<input type="email" name="correo" required>

Resultado

Atributos específicos

  • type : Define el tipo de campo: text, email, number, checkbox y otros.
  • name : Identifica el dato que se envía con el formulario.
  • value : Establece el valor del campo, según su tipo.
  • placeholder : Muestra una pista en los campos de texto que lo admiten; no sustituye a la etiqueta.
  • required : Hace obligatorio completar o seleccionar el campo cuando su tipo lo admite.
  • disabled : Desactiva el campo y evita que su dato se envíe.
  • readonly : Impide editar el valor en los tipos de campo que lo admiten.
  • minlength : Establece la longitud mínima del texto.
  • maxlength : Limita la longitud del texto.
  • min : Fija el valor mínimo en campos numéricos o de fecha y hora compatibles.
  • max : Fija el valor máximo en campos numéricos o de fecha y hora compatibles.
  • step : Define los incrementos válidos en campos numéricos o de fecha y hora compatibles.
  • checked : Marca inicialmente una casilla checkbox o una opción radio.
  • accept : En campos file, sugiere los tipos de archivo que se pueden seleccionar.
  • multiple : Permite varios archivos en file o varias direcciones en email.

Etiqueta <textarea>

Permite escribir texto de varias líneas.

Código

<textarea name="mensaje" rows="4"></textarea>

Resultado

Atributos específicos

  • name : Identifica el texto que se envía con el formulario.
  • rows : Define la altura visible en líneas.
  • cols : Define el ancho visible aproximado en caracteres.
  • minlength : Establece la longitud mínima del texto.
  • maxlength : Limita la longitud del texto.
  • placeholder : Muestra una pista mientras el campo está vacío.
  • required : Hace obligatorio escribir un contenido.
  • readonly : Permite leer y seleccionar el texto, pero no editarlo.
  • disabled : Desactiva el campo y evita que su texto se envíe.

Etiqueta <button>

Crea un botón que activa una acción.

Código

<button type="submit">Enviar</button>

Resultado

Atributos específicos

  • type : Define su función: submit envía, reset restablece y button no tiene acción automática.
  • name : Identifica el dato del botón cuando se utiliza para enviar el formulario.
  • value : Define el valor que se envía con el nombre del botón.
  • disabled : Impide activar el botón.
  • form : Asocia el botón con un formulario, aunque esté fuera de él.
  • formaction : Cambia la URL de envío cuando el botón es de tipo submit.

Etiqueta <th>

Define una celda de encabezado de tabla.

Código

<table><tr><th scope="col">Tema</th></tr><tr><td>HTML</td></tr></table>

Resultado

Tema
HTML

Atributos específicos

  • scope : Indica si el encabezado corresponde a una fila, columna o grupo.
  • colspan : Indica cuántas columnas ocupa la celda.
  • rowspan : Indica cuántas filas ocupa la celda.
  • headers : Asocia la celda con otros encabezados de la tabla.
  • abbr : Proporciona una versión abreviada del texto del encabezado.

Etiqueta <td>

Define una celda de datos de tabla.

Código

Resultado

HTML CSS

Atributos específicos

  • colspan : Indica cuántas columnas ocupa la celda.
  • rowspan : Indica cuántas filas ocupa la celda.
  • headers : Indica qué encabezados describen esta celda.
