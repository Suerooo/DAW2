Ejemplos de páginas web

Ejemplo 1: Página de presentación

Una página inicial con un título, una descripción y un enlace.

Código HTML

<h1>Bienvenido</h1>

<p>Esta es mi primera página web.</p>

<a href="#mas">Seguir aprendiendo</a>

<h2 id="mas">Más contenido</h2>

Resultado

Bienvenido

Esta es mi primera página web.

Seguir aprendiendo

Más contenido

Ejemplo 2: Página personal

Un perfil con información y una lista de intereses.

Código HTML

<header><h1>Mi página personal</h1></header>

<main>

<p>Me gusta aprender desarrollo web.</p>

<h2>Mis intereses</h2>

<ul><li>HTML</li><li>Diseño</li><li>Tecnología</li></ul>

</main>

Resultado

Mi página personal

Me gusta aprender desarrollo web.

Mis intereses

  • HTML
  • Diseño
  • Tecnología

Ejemplo 3: Catálogo de productos

Tarjetas sencillas de productos creadas con HTML y estilos directos.

Código HTML

<h1>Mis productos</h1>

<article class="producto">

<h2>Cuaderno</h2><p>Para tus apuntes.</p>

</article>

<article class="producto">

<h2>Lápiz</h2><p>Para escribir y dibujar.</p>

</article>

Resultado

Para tus apuntes.

Para escribir y dibujar.

Ejemplo 4: Formulario básico

Campos con etiquetas y validación HTML.

Código HTML

<h1>Escríbenos</h1>

<form>

<label for="nombre">Nombre</label>

<input id="nombre" name="nombre" required>

<label for="correo">Correo electrónico</label>

<input id="correo" type="email" required>

<label for="mensaje">Mensaje</label>

<textarea id="mensaje" rows="3" required></textarea>

<button type="submit">Enviar</button>

</form>

Resultado

Escríbenos

Ejemplo 5: Página con multimedia

Una imagen con texto alternativo y un reproductor de audio local.

Código HTML

<h1>Imagen y audio</h1>

<img src="assets/images/example-landscape.svg" alt="Paisaje con montañas" width="360">

<h2>Reproductor de audio</h2>

<audio controls src="assets/audio/ding-sound-effect.mp3"></audio>

Imagen y audio
