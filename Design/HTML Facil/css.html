¿Qué es CSS y para qué sirve?

CSS significa Hojas de Estilo en Cascada. Es un lenguaje que permite cambiar la apariencia de una página web: los colores, la letra, los espacios y la distribución de sus elementos.

HTML define el contenido, como un título o un párrafo. Con CSS podemos hacer que ese título sea azul o que varios elementos aparezcan en columnas. Una misma hoja de estilos puede utilizarse en varias páginas.

¿Cómo se aplica CSS?

En un archivo externo

Escribimos las reglas en un archivo con extensión .css y lo enlazamos dentro de head. Esta web utiliza css/style.css para compartir los estilos entre todas las páginas.

Código HTML

<link rel="stylesheet" href="css/style.css">

Archivo css/style.css

body {

  background-color: #f7fbff;

  font-family: Arial, sans-serif;

}

Dentro del HTML

También podemos escribir las reglas dentro de una etiqueta style situada en head. Solo se aplican a ese documento.

<style>

  p { color: #075bd8; }

</style>

En un elemento

El atributo style permite aplicar estilos directamente a un elemento. Si repetimos el mismo estilo en varios sitios, es más cómodo utilizar un archivo externo.

<p style="color: #075bd8;">Hola</p>

Reglas y selectores

Una regla contiene un selector y unas declaraciones entre llaves. El selector indica qué elementos reciben el estilo. Cada declaración tiene una propiedad y un valor separados por dos puntos y termina con punto y coma.

Código HTML

<p class="texto-css">Mi primer estilo</p>

Código CSS

.texto-css {

  color: #075bd8;

  font-size: 20px;

}

Resultado

Mi primer estilo

El punto selecciona la clase texto-css. color cambia el color de la letra y font-size establece su tamaño.

Por etiqueta

Selecciona todos los elementos de ese tipo. Por ejemplo, todos los párrafos.

p { color: #536883; }

Por identificador

El símbolo # selecciona un id. Cada identificador debe ser único dentro de la página.

<h1 id="titulo">Mi página</h1>

#titulo { color: #075bd8; }

Propiedades básicas

Estas son algunas de las propiedades que podemos utilizar para dar estilo a los elementos.

Color y fondo

color cambia el color del texto y background-color cambia el fondo.

.aviso {

  color: #075bd8;

  background-color: #eaf3ff;

}

Texto

font-family elige la fuente, font-size indica su tamaño y text-align permite alinear el texto.

p {

  font-family: Arial, sans-serif;

  font-size: 18px;

  text-align: center;

}

Espacios y bordes

margin crea espacio fuera del borde y padding entre el contenido y el borde. border dibuja ese borde.

.caja {

  margin: 20px;

  padding: 15px;

  border: 1px solid #075bd8;

}

Tamaño

width establece el ancho y height la altura. max-width limita el ancho para que la caja pueda caber en un contenedor más pequeño.

.caja {

  width: 200px;

  max-width: 100%;

  height: 100px;

}

Organizar elementos con Flexbox

Flexbox distribuye los elementos siguiendo un eje principal, en fila o en columna. Es útil para menús, botones o bloques que queremos colocar uno al lado de otro.

justify-content distribuye el espacio en el eje principal y align-items alinea los elementos en el eje perpendicular. gap deja separación y flex-wrap permite que los elementos pasen a otra línea si no caben.

Código HTML

<div class="flex-ejemplo">

  <span class="caja-css">HTML</span>

  <span class="caja-css">CSS</span>

  <span class="caja-css">JavaScript</span>

</div>

Código CSS

.flex-ejemplo {

  display: flex;

  justify-content: space-between;

  align-items: center;

  flex-wrap: wrap;

  gap: 10px;

}

Crear filas y columnas con Grid

Grid organiza los elementos en filas y columnas. grid-template-columns define las columnas y gap separa las celdas. En este ejemplo, 1fr 1fr reparte el espacio disponible en dos columnas iguales.

Código HTML

<div class="rejilla-ejemplo">

  <span class="caja-css">Uno</span>

  <span class="caja-css">Dos</span>

  <span class="caja-css">Tres</span>

  <span class="caja-css">Cuatro</span>

</div>

Código CSS

.rejilla-ejemplo {

  display: grid;

  grid-template-columns: 1fr 1fr;

  gap: 20px;

}

Resultado

Uno Dos Tres Cuatro

Los recuadros utilizan la clase caja-css del ejemplo anterior. Los dos primeros ocupan la primera fila y los siguientes pasan a la segunda.
