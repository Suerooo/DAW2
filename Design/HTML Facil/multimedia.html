Imágenes, audio y vídeo

Ejemplos de cómo incorporar recursos multimedia con HTML.

Imagen con HTML

La etiqueta img incorpora imágenes. alt añade una descripción alternativa.

<img src="assets/images/example-landscape.svg" alt="Paisaje con montañas">

Reproductor de audio

<audio controls src="assets/audio/ding-sound-effect.mp3"></audio>

Ejemplo de vídeo HTML

La etiqueta video permite reproducir vídeos con controles de reproducción.

<video controls

<source src="assets/video/html-tutorial.mp4" type="video/mp4">

</video>
