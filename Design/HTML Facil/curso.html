Lección 01 de 08

¿Qué es HTML?

HTML es un lenguaje de marcado que sirve para estructurar el contenido de una página web mediante elementos como títulos, párrafos, enlaces e imágenes.

El navegador interpreta las etiquetas y muestra el contenido.

Lección 02 de 08

Estructura de una página

Un documento comienza con <!DOCTYPE html>. El elemento html contiene head (información del documento) y body (contenido visible).

<!DOCTYPE html>

<html lang="es">

<head>

<meta charset="UTF-8">

<title>Mi web</title>

</head>

<body>

<h1>Hola, mundo</h1>

<p>Mi primera página.</p>

</body>

</html>
